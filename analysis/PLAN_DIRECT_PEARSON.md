# Direct Pearson：执行规划与完成记录

创建：2026-11-07；更新：2026-11-08。**本文件的分析执行任务已完成并核验。**结果解释与限制见[分析摘要](ANALYSIS_BRIEF_20261108.md)，逐项证据见[完成审计](COMPLETION_AUDIT_20261108.md)。论文改写、合作者对framing的决定和正式rebuttal仍属于后续修稿工作。

## 目标与方法

直接量化每个模型层与脑内表征几何的关联强度和空间分布，再检验不同层地图的空间关系及图片抽样稳定性。

保留BrainIAK Searchlight + MPI框架，由Slurm启动逐被试worker，回调复用已经与旧ModelSim及SciPy验证的`direct_pearson`。每个searchlight同时计算12层有符号Pearson r。

```text
当前cope和模型RSM
  → Slurm / MPI / BrainIAK Searchlight
  → 逐人12层直接r图、覆盖和QC
  → 被试层级Fisher组汇总
  → 新统计推断、跨层空间比较及不确定性
  → NSD对照、100次互补图片分半、可靠性背景
```

BrainIAK/MPI是工程框架，直接Pearson是评分定义。具体汇总与推断细节是本轮明确记录的技术选择，不代表合作者已经确认全部方法细节。实际计算、绘图和结果存储均在Milgram；本机只保存经授权下载的预览、汇总和核查记录。

## 固定分析定义

- 每人、每层、每中心计算模型RSM和脑RSM严格上三角之间的Pearson r：16图为120条，8图为28条。
- 保留正负号，不平方、不做跨被试预测回归、不按置换null标准化。
- radius=3，完整7×7×7 Cube。mask选择中心，不筛掉Cube内体素；排除距数组边缘不足3体素的中心。无定义相关保留NaN，另存覆盖。
- 模型与脑使用完全相同的图片索引；先保存单人r，再以`tanh(mean(atanh(subject r)))`汇总，另存有效被试数。
- 主空间比较固定为30人、12层共同有效的191696个体素，不按各层显著性选点。
- 图的颜色展示原始关联r；显著性来自新分析，独立表示。120条RSM条目不视为120个独立实验样本。

详见[METHODS_DIRECT_PEARSON.md](METHODS_DIRECT_PEARSON.md)。

## 阶段4：正式推断与跨层空间比较——完成

运行前固定`configs/inference_direct_rsa.json`和方法文档。作业29531037完成：

- 群体单位为30名参与者，现有16图固定；检验平均Fisher-transformed关联为零。
- 10000次被试符号翻转，同一被试的符号在全部层和体素共享；双侧max-|t|联合校正12层×191696中心，即2300352项检验。
- 校正p用`(1+exceedances)/(10000+1)`，alpha=.05。要求独立参与者及零假设下误差向量联合对称。
- 另完成1000次被试bootstrap的12×12空间相关pointwise区间和11对相邻层摘要；不当作同时覆盖区间或新图片集推断。

独立QC29531065核对全部t/p/mask、两个完整family的随机化最大值和1000个bootstrap矩阵通过。地图颜色仍为原始r。

本轮正式检验选择被试符号翻转，**不是图片标签置换**，两者零假设与推广范围不同。若另做图片标签置换，仍须同一置换同步重排RSM两轴并明确跨被试协调，不得把120条目独立打乱。

产物：`inference/`下12张新p图及mask、null最大值、空间矩阵区间、相邻层CSV和新显著性轮廓预览。低空间相关本身不证明不同计算阶段已定位。

R2采用seed=20261107的100次互补8/8抽样，含98个不同无序划分。两半分别计算逐人r和30人Fisher组图，保存两半地图、每次12×12跨半矩阵、同层/异层及差值分布。缓存完整脑RSM只减少重复计算，不改变评分定义；30人缓存均在全部共同位置复现原r图。

分半29530981、汇总29530982和独立QC29531064完成：100组地图及矩阵核验通过；从原始cope独立重算划分0和99的抽样位置，组r最大误差6.7461e-9。重复划分共享图片与被试，分位数为描述性分布，不是独立实验的置信区间。

补充空间检查29531161固定为既有13个视觉ROI并集与共同覆盖的5463体素，保留主范围不变，不按层显著性选择。结果显示部分层的稳健性依赖比较空间，应同时报告。

NSD与合成数据的被试、重复和刺激设计不同，不能把原始r差异全部归因于优化方法；分半也不证明对独立新生成图片集的泛化。
