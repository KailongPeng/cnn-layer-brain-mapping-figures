# Direct Pearson结果摘要与修稿讨论要点

2026-11-08。计划中的全脑、群体检验、NSD及图片分半分析已完成，数值QC和图像审查通过。计算与绘图均在Milgram，本机仅保存预览、汇总和核查记录。此文件是结果解释材料，不是邮件草稿或rebuttal。

## 主要发现

**当前结果需要收缩“稳定定位多个模型计算阶段”的表述。**关联强度、空间差异与图片子集可靠性应一起呈现。模型空间的成功解耦和脑空间的稳定定位是两项不同证据。

合成数据的组r总体较弱。修正坐标后的ROI中，12层的平均原始r范围如下；这些是每人ROI内r算术均值再跨被试平均，不是峰值或组t。

| ROI | 12层模型r均值范围 | LOSO / inclusive可靠性估计 |
|---|---:|---:|
| V1 | −0.0461～0.0216 | 0.0461 / 0.1598 |
| V2 | −0.0246～0.0166 | 0.0306 / 0.1472 |
| V3 | −0.0224～0.0263 | 0.0459 / 0.1609 |
| hV4 | −0.0156～0.0209 | 0.0235 / 0.1506 |
| VO | −0.0308～0.0499 | 0.0852 / 0.2022 |
| PHC | −0.0573～0.0629 | 0.1331 / 0.2459 |
| LO | −0.0611～0.0514 | 0.1626 / 0.2582 |
| hMT | −0.0385～0.0334 | 0.0890 / 0.2179 |

这些可靠性估计与模型r使用同一脑RSM、同一ROI和相同平均顺序。可靠性并非处处为零，但估计本身有限；表中差距不是已经完成的模型优劣显著性检验，也不应直接转成“解释了多少百分比”。

严格的12层×共同空间联合双侧max-|t|校正后，逐层显著中心数为`9, 0, 1, 0, 9, 0, 9, 0, 0, 0, 0, 13`。这些是层×中心条目，不能合称41个独立脑区，也不能全部称为正关联。检验有独立参与者与符号对称性假设，且条件固定为现有16图；未过这个严格family阈值不等于真实效应严格为零。

## 图片分半是本轮关键限制

100次随机8/8抽样中，全共同空间的同层跨半空间相关中位数跨层范围为−0.0793～0.0782。限制到独立解剖视觉ROI并集后范围为−0.0847～0.3356；第7层约0.3356，第2层约0.1167，其余多接近零。

因此，稳健性依赖层和比较空间。视觉范围中部分层改善，不能据此概括所有层稳定；全脑相关弱也不宜抹去第7层在该补充范围中的相对改善。100次抽样的2.5–97.5%分位范围在各层均跨零，波动较大；这些分位数不是100次独立实验的置信区间。

这项结果直接回应图片抽样问题。原来的被试分半只检验同一批图片下的人群可重复性，不能替代它；8图较噪也不能证明16图已经足够，更不能声称独立合成另一套16图仍会泛化。

## NSD对照如何使用

NSD的1536张逐人逐集r图、分层组汇总与空间比较已完成。共同有效范围为302573体素；与合成数据对照图使用交集191258体素和统一色标。NSD部分层在视觉区域呈现更清楚的关联，比较图可直接查看，不再比较两种null标准化z的色值。

该比较仍同时包含被试、图片集、重复测量和设计差异。它提供有用的关联背景，尚不能把两组r差异全部归因于刺激优化方法。NSD图在本轮为描述性对照，未沿用旧R²显著性mask。

## 建议带回团队讨论的内容

1. 把未阈值化r、单独的新显著性标记、可靠性与图片分半限制放入主论证，不能继续全部放在补充材料。
2. 将“模型层RSM在模型空间更可区分”与“对应不同皮层计算阶段”分开。低跨层空间相关在低可靠性时也可能出现，需要避免把空间不同本身当作机制定位证据。
3. 根据原始关联和分半表现重审标题、摘要与主图解释；对第7层的相对稳健性说明空间范围及大幅波动，避免事后将补充范围替换为主分析。
4. 旧回归结果可以作为不同预测问题的补充，明确统计量与解释；不把旧R²或其null z重命名为Pearson效应量。
5. 如果保留独特贡献分析，先讨论残差化定义、拟合范围与对应关联量。本轮没有新的residual Pearson地图，不能暗示Fig.6已经由它替换。

本轮已具备实际结果供合作者决定framing；无需继续停留在“能否尝试direct correlation”的阶段。主文改写与最终方法取舍仍需团队决定。
