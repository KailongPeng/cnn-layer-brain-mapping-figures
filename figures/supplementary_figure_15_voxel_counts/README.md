# Figure S15: Significant-voxel counts by NSD set

For each of 16 NSD image sets and 12 model layers, this analysis counts
significant voxels after applying the representational-stability mask. It
reports the non-residual and residual methods on the same scale.

`analysis/Sfig8.py` loads the set-level outputs generated by Figures 4 and 6,
counts the masks, and produces the two panel-level matrices.
