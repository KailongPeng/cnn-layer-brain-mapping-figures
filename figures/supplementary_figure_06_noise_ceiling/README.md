# Figure S6: Noise ceiling and representational stability

At each searchlight, the lower noise-ceiling estimate correlates each held-out
participant's image RSM with the mean RSM of the remaining participants. The
result is averaged across leave-one-participant-out folds and reported as raw,
unthresholded Pearson correlation.

`analysis/noise_ceiling/` contains the BrainIAK/MPI searchlight for synthesized
and NSD data. The remaining scripts produce the surface, Wang-atlas ROI, and
stability-versus-noise-ceiling panels. ROI error bars are SEM across voxels.
